# Sistema Web JSP - Semana 05

## Descripción del proyecto

Aplicación web desarrollada con Java EE 10 utilizando JSP, Maven y Apache Tomcat.

El proyecto permite mostrar información de productos mediante una interfaz web con archivos JSP, CSS, JavaScript y JSON.

## Tecnologías utilizadas

- Java EE 10
- JSP (Java Server Pages)
- Maven
- Apache Tomcat
- HTML5
- CSS3
- JavaScript
- JSON
- Docker
